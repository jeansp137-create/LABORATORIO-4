# Laboratorio 4: Modelo de Negocio y Requerimientos - Cajero Automático (ATM)

## Información General
* **Asignatura:** Ingeniería de Software
* **Metodología:** Modelado de Dominio y Requerimientos de Stephen R. Schach
* **Proyecto:** Sistema de Información del Cajero Automático
* **Autor:** Julián David Fernández Ruiz

## Descripción del Proyecto
Este repositorio contiene la especificación formal de requerimientos y el modelo de negocio para un **Cajero Automático (ATM)**. El modelado define la interacción entre los actores y el sistema mediante la estructuración de casos de uso y diagramas UML.

## Contenido del Repositorio
* `CAJERO.pdf`: Documento de especificación de requerimientos, modelo de negocio y descripciones formales de casos de uso.
* `Diagrama sin título.drawio.pdf`: Diagramas de Casos de Uso (Individuales y General) desarrollados en Draw.io.

## Actores del Sistema
* **Cliente:** Usuario final que interactúa presencialmente con el cajero automático.
* **Sistema Central Bancario:** Sistema externo encargado de la validación de credenciales, consulta de saldos y autorización transaccional.
* **Operador de Mantenimiento:** Personal técnico responsable de la logística de reabastecimiento de efectivo y mantenimiento del hardware.

## Casos de Uso Especificados
1. **Autenticar Cliente:** Validación segura de credenciales y código PIN.
2. **Retirar Efectivo:** Transacción financiera de extracción de dinero previa verificación de saldo.
3. **Consultar Saldo:** Consulta e impresión del estado financiero de cuentas.
4. **Abastecer Efectivo:** Reabastecimiento de billetes e inventario físico por parte del operador.
